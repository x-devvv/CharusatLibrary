<h3 id="-overview">🚀 Overview</h3>

<p>
The CHARUSAT Library Management System is a full‑stack MERN application that streamlines book cataloging, role‑based access, transactions, fines, reservations, notifications, and analytics through a modern, responsive interface.
</p>

<h4>🎯 Problem Statement</h4>
<ul>
  <li>Legacy library tools are fragmented and lack real‑time updates, leading to delays and poor user experience.</li>
  <li>This system delivers instant availability, automated workflows, role‑based security, and actionable analytics in one platform.</li>
</ul>

<h3 id="-key-features">✨ Key Features</h3>

<h4>🔐 For Administrators</h4>
<ul>
  <li>Role management with fine‑grained permissions and audit logs.</li>
  <li>Library policies: loan duration, fine rates, and borrowing limits.</li>
  <li>Bulk operations: book import/export (CSV), user onboarding, and reports.</li>
</ul>

<h4>📖 For Librarians</h4>
<ul>
  <li>Fast check‑in/out, renewals, holds, reservations, and waitlists.</li>
  <li>Advanced search with filters, ISBN validation, and category tags.</li>
  <li>Circulation, inventory, and overdue insights with exports.</li>
</ul>

<h4>🎓 For Students & Members</h4>
<ul>
  <li>Smart discovery with filters, recommendations, and personal library.</li>
  <li>Due reminders, reservation notifications, and account overview.</li>
  <li>Responsive experience across devices with accessible navigation.</li>
</ul>

<h3 id="-docker-deployment">🐳 Docker Deployment</h3>

<h4>Quick Start</h4>
<pre><code># From repo root
docker-compose up -d
docker-compose logs -f
# FE: http://localhost:3000, BE: http://localhost:5000
</code></pre>

<h4>docker-compose.yml (excerpt)</h4>
<pre><code>services:
  mongodb:
    image: mongo:6
    restart: always
    volumes:
      - mongo_data:/data/db

  backend:
    build: ./server
    env_file: ./server/.env
    ports:
      - "5000:5000"
    depends_on:
      - mongodb

  frontend:
    build: ./client
    ports:
      - "3000:80"
    depends_on:
      - backend

  nginx:
    image: nginx:alpine
    volumes:
      - ./infra/nginx.conf:/etc/nginx/nginx.conf:ro
    ports:
      - "80:80"
    depends_on:
      - frontend

volumes:
  mongo_data:
</code></pre>

<h3 id="-configuration">🔧 Configuration</h3>

<h4>Backend (.env)</h4>
<pre><code># Database
MONGODB_URI=mongodb://localhost:27017/charusat_library
DB_NAME=charusat_library

# JWT
JWT_SECRET=your-super-secret-jwt-key
JWT_EXPIRE=7d

# Email (SMTP)
EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_USER=your_email@gmail.com
EMAIL_PASS=your_app_password

# App
NODE_ENV=development
PORT=5000
FRONTEND_URL=http://localhost:5173

# Policies
FINE_PER_DAY=2.00
LOAN_PERIOD_DAYS=14
MAX_BOOKS_PER_USER=5
RESERVATION_HOLD_DAYS=3

# Cloudinary (optional)
CLOUDINARY_CLOUD_NAME=your-cloud
CLOUDINARY_API_KEY=your-key
CLOUDINARY_API_SECRET=your-secret

# Bootstrap Admin
ADMIN_EMAIL=admin@charusat.ac.in
ADMIN_PASSWORD=Admin@123456
</code></pre>
